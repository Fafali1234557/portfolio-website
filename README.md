# Saviour Fafali Ankugah — Portfolio

Personal portfolio website showcasing my skills, programming projects, experience, and certifications.

## What's included
- `index.html` — full portfolio website with embedded styling, JavaScript and most images.
- `assets/documents/CodeAlpha_App_Development_Certificate.jpg` — certificate image.
- `assets/documents/CodeAlpha_Letter_of_Recommendation.pdf` — recommendation letter.

Some technology icons and fonts are loaded from external CDNs and require internet access.

## Publish with GitHub Pages
1. Create a new **public** repository named `portfolio-website`.
2. Upload `index.html`, `README.md`, and the complete `assets` directory to the repository root.
3. Open **Settings → Pages**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. Visit `https://Fafali1234557.github.io/portfolio-website/` when deployment finishes.

The site can also remain deployed on Netlify. Publishing on GitHub Pages is optional.
